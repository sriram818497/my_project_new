## 🎨 Brand Color System

### **Primary Green Shades:**
```css
#1cd35c - Main brand green (buttons, accents, icons)
#17a84b - Darker green (gradients, shadows)
#19b850 - Hover state green
#20e066 - Light green (highlights)
#25f075 - Bright green (gradient peaks)
```

### **Background Colors:**
```css
Gray-900 (#111827) - Dark background start
Gray-800 (#1F2937) - Mid background
Black (#000000) - Background end
```

### **Supporting:**
```css
White (#FFFFFF) - Text, cards
Gray shades - Borders, secondary text
```
